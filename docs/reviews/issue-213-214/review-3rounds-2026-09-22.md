## 실측으로 확정한 주요 결함

**펜스 닫힘 (CommonMark)** — 닫는 펜스는 같은 문자·길이 이상 + **뒤에 공백/탭만**.
```` ```bash ```` 를 닫는 펜스로 오인해 안쪽 헤딩이 누출했다.

**후보 키 정규화** — `existing` 매칭은 lowercase 인데 집계 키는 원본 케이스였다.
`CaseVar`/`casevar` 가 각각 count=1 → min_count 미달 → **후보가 통째로 소실**됐다.

**sources 이중집계** — 출현 파일 수를 캡된 `refs` 로 판정해 4번째 파일부터 부풀려졌다.
파일 A~E + D 2회 → 실제 5개 파일인데 sources=6 으로 보고됐다.

**`# C#` → `C` 회귀** — 2차 수정에서 제가 넣은 정규식이 닫는 `#` 를 무조건 벗겼다.
CommonMark 는 앞에 공백이 있을 때만 제거한다. 언어명이 훼손되고 key 가 `c`(len<2)로 소실됐다.

**JSON 직렬화** — `seen` 을 후보 dict 안에 set 으로 넣어 `--json` 이 죽었다.
단위 테스트는 통과하고 **실행 경로에서만** 드러났다.
