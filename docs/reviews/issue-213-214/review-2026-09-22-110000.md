## [mid] 펜스 길이 미검증 — 중첩 펜스에서 헤딩 누출 (실재)

```
입력:
````          ← 4-backtick 열림
# outer
```           ← 3-backtick (코드는 닫힘으로 오인)
# inner       ← 실제로는 펜스 안
````
# real

수정 전 출력: ['inner (펜스 안)']      ← 누출
기대(CommonMark): ['real']
```

**CommonMark**: 닫는 펜스는 여는 펜스와 **같은 문자 + 길이 이상**이어야 닫힙니다.
길이를 보지 않으면 안쪽 헤딩이 누출합니다. 중첩 펜스 예시가 있는 source 에서 실제 발생
가능하며, **원래 노이즈를 만든 유형의 콘텐츠**입니다.

**수정**: `fence_len` 을 추적해 `ln >= fence_len` 조건을 추가했습니다.

```
수정 후: ['real']  ✅
```

## 리뷰가 정확하다고 확인한 것

1. **펜스 상태기계 나머지 케이스** — ``` vs `~~~` 문자 구분 · 불일치 마커 시 펜스 유지 ·
   닫히지 않은 펜스가 뒤를 가림 · 들여쓴 펜스 줄 · 언어 태그 무시. **정상 펜스에서 실제
   헤딩이 삼켜지지 않고, 같은 길이 펜스에서 누출도 없음**
2. **`_is_excluded_heading` / `_TEMPLATE_RE`** — `/` 규칙이 넓지만 **이 파일시스템 기반
   위키에서 페이지 이름에 `/` 가 들어갈 수 없으므로** 실제 페이지명을 버리지 않음.
   playbook 이 명시한 제외 신호와 코드가 일치 — **모순 없음**
3. **`sanitize_hanja` / `summarize_hanja`** — 범위 `U+4E00-U+9FFF`·`U+3400-U+4DBF` 가
   정확하고 **양끝 포함** (경계값 `U+4DBF`/`U+4DC0`/`U+9FFF`/`U+A000` 검증). 한글·가나·
   ASCII 불변. run 단위 집계 + 내림차순 정렬이 문서화된 형식과 일치
4. **`find_candidates`** — `.archived` 제외 · alias 대소문자 무시 · `min_count` 임계 ·
   `rel not in refs` 중복 제거 + refs 3건 상한. 버그 없음
5. **테스트 비-vacuous** — `test_code_fence_headings_excluded` 는 **닫힌 펜스 뒤 재개**를
   요구하므로 첫 펜스에서 멈추는 파서는 실패한다. 두 핵심 펜스 테스트가 실제 마커를 써서
   상태기계 동작을 증명함
6. **playbook ↔ 코드 정합** — `lint.md` 가 나열한 제외 규칙이 코드가 구현한 것과 정확히
   동일하고, 코드에 없는 규칙을 playbook 이 주장하지 않음 (양방향 확인)

### ⚠️ `[[...]]` 링크 전환을 채택하지 않은 근거 (이슈 제안과 다름)

이슈 §5(b) 는 판정 근거를 `[[...]]` 로 한정하라 제안했으나 **실측 결과 동작하지 않습니다**:

```
source 전체 [[...]] 537건 분류
  plain     305   '경로' · '링크' · '-'          ← 플레이스홀더·문법 예시
  path      148   'nas/article/....md'           ← log.md 경로 표기
  template   41   'gdrive/...' · 'analyses/...'
  shell      32   '-z $KUBECTL_COMPLETE'         ← bash [[ ]] 조건 연산자
  url        11
```

`[[` 는 마크다운 위키링크이자 **bash 조건 테스트 연산자**라 문자열로 구분 불가합니다.
링크 기반으로 바꾸면 후보가 **13 → 26건으로 증가**합니다 (실측).

**진짜 원인은 "헤딩"이 아니라 "코드 펜스 내부 스캔"** 이었습니다:

```
후보 13건의 펜스 내부 여부
  또는                펜스내 3 / 펜스밖 0
  저장소 클론           펜스내 2 / 펜스밖 0
  wikihub.yaml       펜스내 2 / 펜스밖 0
  … (11건이 펜스 내부)
  Superpowers        펜스내 0 / 펜스밖 2   ← 예외
  설치 및 실행          펜스내 1 / 펜스밖 1   ← 예외
```

**13건 중 11건이 펜스 내부**였습니다. 이 결정의 근거를 모듈 docstring 과 spec 에 남겼습니다.
