## [high] 반증 — 실측 근거

리뷰 주장: "NFC 경로로 mount 를 열면 NFD 원본에서 실패한다"

**반증 1 — mount 에서 NFD/NFC 가 같은 파일을 가리킨다**

```
$ python3 (NAS mount 실측)
  NFD 경로 exists: True
  NFC 경로 exists: True
  같은 inode?      True        ← 두 경로가 동일 inode
  실본 이름 NFC 여부: False     (디렉터리 엔트리는 NFD)
```

**반증 2 — `_read_from_mount` 를 실제 호출해도 정상 read**

```
$ _read_from_mount(source_relpath=<NFC>, mime=application/pdf)
  extraction_status = failed
  bytes_written     = 4969676        ← 파일을 정상적으로 읽음
  reason            = import: No module named 'pdfminer'

$ _read_from_mount(source_relpath=<NFD>)  # 대조군
  bytes_written     = 4969676        ← 완전히 동일
```

`extraction_status=failed` 의 원인은 **`pdfminer` 미설치(#186 계층)** 이며 경로 문제가 아닙니다. NFC·NFD 양쪽이 **바이트 수까지 동일**합니다.

**반증 3 — 테스트가 결함을 실제로 검출**

```
$ (정규화 없이 NFD key 로 대조)
  entries=2 ['created', 'deleted']      ← 결함 상태
$ pytest -k nfc
  2 passed                              ← 수정 상태 검출
```
