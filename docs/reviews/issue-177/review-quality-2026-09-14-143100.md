## 리뷰 오독 정정 (PASS 판정 자체는 유지)

subagent 는 `"${openai_env[@]}"` 를 **unquoted** 로 서술하며 "word-splitting 이 의도적"이라 했으나,
실제 코드는 **quoted** (`cat -A` 확인) 이며 그것이 정답이다. 실측:

```
unquoted: 값에 공백이 있으면 원소가 쪼개짐  → [OPENAI_API_KEY=key] [with] [space]
quoted:   원소 보존                        → [OPENAI_API_KEY=key with space]
```

→ 코드는 수정하지 않는다.

## [low] 보고만 (본 이슈 범위 밖, 무변경)

`OPENAI_API_KEY="$api_key"` 는 `api_key` 가 비어도 항상 전달된다 —
`OPENAI_BASE_URL` 과 대칭이 아니다. 기존 동작이며 본 패치가 만든 문제가 아니다.
